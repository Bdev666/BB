# โครงสร้างโค้ด BinderDash (สำหรับคนแก้โค้ด)

## ไฟล์หลัก (`src/`)
| ไฟล์ | หน้าที่ |
|---|---|
| `main.js` | เริ่มโปรแกรม หน้าต่างเกม/Dashboard อ่านข้อมูลเกม แจ้งเตือน คำสั่งจาก Dashboard ต่อใหม่ ตารางเวลา |
| `core/hub.js` | ที่เดียวสำหรับชื่อที่ใช้ข้ามไฟล์ (`HUB.x`) |
| `game-adapter.js` | ถอดข้อความจากเกมเป็นเหตุการณ์ |
| `session-data.js` | ข้อมูลของแต่ละบัญชี (สรุปแบบหน้าพักจอ กระเป๋า เหตุการณ์) |
| `build-lab.js` | Build Lab (ใช้ตัวคำนวณดาเมจของเกม) |
| `selftest.js` | ทดสอบระบบ บันทึกดาเมจจริง/สถิติ รวม log |
| `store.js` | ตั้งค่าและข้อมูลที่เก็บไว้ |

| ไฟล์ | ทำอะไร |
|---|---|
| `potions.js` | ซื้อยาในช่องลัดเมื่อเหลือน้อย |

| `market-watch.js` | ติดตามราคาตลาด |
| `combat.js` | จับเวลาตีบอส และทดลองจริง A/B |
| `farm.js` | สมุดกำไรต่อแมพ เช็คปุ่มเกม ผู้คุมตัวละคร แก้ AUTO ค้าง กลับจุดฟาร์ม เดินทาง หาที่ฟาร์มคุ้มสุด |
| `rewards.js` | รับของจดหมาย/Pass |
| `crowd.js` | ย้าย CH เมื่อคนเยอะ |
| `bounty.js` | ทำค่าหัวรายวัน |
| `worldboss.js` | ไปตีบอสโลกและกลับ |
| `calibration.js` | เรียนรู้ค่าปรับ Build Lab จากดาเมจจริงและการตีบอส |
| `spam.js` | สแปมสกิล: กดปุ่มแถบสกิลที่เลือก (1–9) ซ้ำๆ ระหว่างที่ AUTO ตี หยุดเองตอนตาย/พักจอ/เดินทาง/พิมพ์แชท |

## ผู้คุมตัวละคร (ใครสั่งตัวละครได้ก่อน)
บอสโลก / กลับจุดฟาร์มหลังบอส > ค่าหัว > หาที่ฟาร์ม / เดินทางไปแมพที่เลือก > ย้าย CH > แก้ AUTO ค้าง / คืนแรม
ทุกระบบถาม `mayAct()` ก่อนเดินทางหรือกด AUTO (ใน `features/farm.js`)

## ตารางเวลา (`SCHEDULE` ใน `main.js`)
ทุกงานที่รันเป็นรอบอยู่ในตารางเดียว เรียงจากถี่ไปห่าง: อ่านหน้าเกม (1 วิ) → ต่อใหม่ (5 วิ) → แจ้งเตือน/เกิดที่เดิม/ฟาร์ม (15 วิ) → ค่าหัว/ย้าย CH (20 วิ) → บันทึก (5–10 นาที) → เรียนรู้ค่าปรับ (1 ชม.)
แต่ละงานมีตัวกัน: งานหนึ่ง error ไม่ทำให้งานอื่นหยุด และบันทึกลง log

## ก่อนส่งโค้ด
`npm run check` ตรวจไวยากรณ์ทุกไฟล์, สคริปต์ที่ส่งเข้าหน้าเกม, และเทสต์การนับในสรุป
