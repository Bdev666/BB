# BinderDash · คู่มือติดตั้งและใช้งาน (สำหรับเพื่อนและสมาชิกกิลด์)

BinderDash คือโปรแกรมแฟนเมดสำหรับเล่น Binder Town หลายบัญชีในจอเดียว ไม่เกี่ยวข้องกับผู้พัฒนาเกม แจกฟรี ไม่ได้ขาย

> ⚠ อ่าน[กติกาของเกม](https://bindertowngame.com/terms.html)เรื่องโปรแกรมเสริมและการเล่นหลายบัญชีก่อนใช้ การใช้งานเป็นความรับผิดชอบของผู้ใช้เอง

## ดาวน์โหลด

หน้าดาวน์โหลดเวอร์ชันล่าสุด: https://github.com/Bdev666/BB/releases/latest

| เครื่อง | ไฟล์ |
|---|---|
| Windows 10/11 | `BinderDash-Setup-x.y.z.exe` |
| Mac (Intel และ M1/M2/M3/M4) | `BinderDash-x.y.z-mac.dmg` |

## ติดตั้ง

**Windows**
1. เปิดไฟล์ `BinderDash-Setup-….exe`
2. ถ้า Windows ขึ้นหน้าจอสีฟ้า "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway** (โปรแกรมไม่ได้ซื้อใบรับรองจาก Microsoft จึงขึ้นหน้านี้)
3. ติดตั้งตามขั้นตอนได้เลย
4. เวอร์ชันใหม่จะเด้งการ์ดอัปเดตใน Dashboard กด "อัปเดตตอนนี้" แล้วโปรแกรมติดตั้งและเปิดใหม่เอง

**Mac**
1. เปิดไฟล์ `.dmg` แล้วลาก BinderDash ไปไว้ในโฟลเดอร์ Applications
2. เปิดครั้งแรก: **คลิกขวาที่แอป แล้วเลือก Open** จากนั้นกด Open อีกครั้ง
   - ถ้ายังเปิดไม่ได้ ไปที่ System Settings > Privacy & Security เลื่อนลงไปกด **Open Anyway**
3. Mac อัปเดตเองในแอปไม่ได้ การ์ดอัปเดตจะเปิดหน้าดาวน์โหลดให้ โหลด `.dmg` ใหม่แล้วลากทับของเดิม ข้อมูลบัญชีและการตั้งค่าอยู่ครบ

## เริ่มใช้งาน

1. เปิดโปรแกรม จะเจอ Dashboard พร้อม "บัญชี 1"
2. กดปุ่ม **+ เพิ่ม** (มุมรายการบัญชี) ตามจำนวนตัวละครที่จะเล่น สูงสุด 10 บัญชี
3. เลือกบัญชีแล้วกด **เปิดเกม** (หรือดับเบิลคลิกที่บัญชี) แล้วล็อกอินในหน้าเกม (Google / Discord / Guest) ทำครั้งเดียว โปรแกรมจำไว้ให้ แต่ละบัญชีแยกการล็อกอินกัน
4. ซ่อนหน้าเกมได้ เกมยังเล่นต่อ ดูทุกตัวได้ที่ Dashboard
5. ทางลัด: **Ctrl+Shift+D** เปิด/ปิด Dashboard · **Ctrl+1–9** เลือกบัญชี · **F11** เต็มจอ (Mac ใช้ Cmd แทน Ctrl)

## ระบบที่ใช้เงินในเกม (ปิดไว้เป็นค่าเริ่มต้น เปิดเองใน ตั้งค่า > ทั่วไป)

| ระบบ | ใช้อะไร |
|---|---|
| ↺ ตายแล้วเกิดที่เดิมทันที | 5,000 G ต่อครั้งในแมพฟิลด์ (บอสโลกฟรี) · เกิดทันทีทุกครั้ง |
| 🧪 ซื้อยาในช่องลัดเองเมื่อเหลือน้อย | Silver ตามราคาร้าน · ตั้ง Silver ขั้นต่ำที่จะไม่แตะได้ · ซื้อจากที่ไหนก็ได้ต้องเป็น Premium |
| 📜 ทำค่าหัวอัตโนมัติ (ปุ่มในแต่ละบัญชี) | ไม่เสียเงิน · เดินทางด้วยปุ่มของเกม · ข้ามใบที่มอนเลเวลสูงเกิน · รับรางวัลเอง |
| 🌋 ไปตี World Boss เองเมื่อเริ่ม | ไม่เสียเงิน (เข้าฟรี) · จบแล้วพากลับที่เดิม |

การขาย ย่อย และลงตลาดทุกครั้ง โปรแกรมจะถามยืนยันก่อนเสมอ และของที่ล็อกไว้ในเกมจะไม่ถูกย่อยหรือขาย

## เจอปัญหา

1. ตั้งค่า > **ทดสอบระบบ** > กด **เริ่มทดสอบ** (ไม่ขาย ไม่ย่อย ไม่ใช้เงิน ถ้าไม่เปิดสวิตช์ใช้เงิน)
2. กด **📦 รวม log** จะได้ไฟล์ `BinderDash-log-….txt` บน Desktop
   - ชื่อบัญชีและชื่อตัวละครในไฟล์ถูกแทนด้วย acc 1, acc 2 … และไม่มีรหัสผ่านหรือ token
3. ส่งไฟล์นั้นให้คนที่แชร์โปรแกรมให้คุณ พร้อมเล่าว่าเกิดอะไรขึ้น

## ข้อมูลอยู่ที่ไหน

ทุกอย่างอยู่ในเครื่องคุณเท่านั้น ไม่มีการส่งข้อมูลออกไปที่ไหน (ยกเว้น Telegram ถ้าคุณตั้งเอง)
- Windows: `%APPDATA%\BinderDash`
- Mac: `~/Library/Application Support/BinderDash`

ถอนการติดตั้งแล้วอยากลบข้อมูลล็อกอินด้วย ให้ลบโฟลเดอร์นี้
